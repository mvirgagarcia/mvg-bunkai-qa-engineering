## Refinement notes (ATP-vs-code)
1. Guard counts runs of **ANY status**, not only "active" (`0032:244-250`).
2. DELETE success body is double-nested: `{"deleted":{"deleted":true,"id":...}}` — assert that shape, not `{"deleted":true}`.
